# MiniMiku Linux is Free Software

All of MiniMiku Linux is free software.

MiniMiku Linux is developed with the principles of software freedom in mind. Everyone should have the freedom to use, study, modify, and redistribute the software.

All components of MiniMiku Linux are intended to be free software, including:

- The Linux kernel and MiniMiku-specific kernel modifications.
- MiniMiku drivers and built-in components.
- System utilities and applications.
- Build scripts and development tools.
- Configuration files and documentation.

MiniMiku Linux does not intend to restrict users from studying, modifying, sharing, or improving its software.

## Software Licensing

MiniMiku Linux software is distributed under its respective free software licenses. Individual components may have different licenses, which are documented in their source files or accompanying license information.

Third-party software retains its original licensing terms.

## Our Principle

**Software should be free to use, study, modify, and share.**

MiniMiku Linux is free software. Its development is built around software freedom.
