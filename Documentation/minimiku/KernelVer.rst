==============
Kernel Version
==============

:Version: 7.4.0-rc2
:Status: Release Candidate

Overview
========

This document specifies the target Linux kernel version **7.4.0-rc2**.

Verification
============

To verify the active kernel version on a running system, execute::

    uname -r

The expected output should match ``7.4.0-rc2``.

.. note::
   ``7.4.0-rc2`` is a release candidate intended for testing and development purposes.
